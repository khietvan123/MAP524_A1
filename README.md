
# Android Registration App

This is a simple Android application built with **Kotlin** that demonstrates the use of a multi-screen layout with basic form validation and navigation. The app allows users to fill out a registration form and, upon successful validation, displays a "Thank You" screen.

## 🚀 Features

- Splash screen (optional depending on your implementation)
- Registration form:
  - First Name
  - Last Name
  - Email
  - Password and Confirm Password
  - Gender selection (Radio Buttons)
  - Terms and Conditions (Checkbox)
- Password match validation
- Navigation to a confirmation screen
- Toast messages for error feedback

## 🛠 Technologies Used

- Kotlin
- Android SDK
- XML Layouts with ConstraintLayout
- Android Studio

## 📱 Screens
1. **Home Screen** - Display welcoming message.
2. **Registration Form** – Users input their details.
3. **Thank You Screen** – Shown after successful registration.

## ✅ Validation Rules

- All fields must be filled out.
- Password and Confirm Password must match.
- The user must agree to Terms and Conditions before proceeding.

## 🧪 How to Run

1. Clone the repository:
   ```bash
   https://github.com/khietvan123/MAP524_A1.git
   ```
2. Open in Android Studio.
3. Connect an Android device or use the emulator.
4. Click **Run**.
